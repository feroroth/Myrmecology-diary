### MYRMECOLOGY DIARY

## What is myrmecology?
***Myrmecology is a study of ants***, Myrmecologists are peoples who do this.

## What is this code for?
I made it to track my catched atns queens so I can better know when I can see them in the future. It's a simple code made in ***python***
and using ***tkinter library*** for GUI enviroment.

## How does it work?
It works by storing data of catched ants into .txt files, so it stay even after code is closed. It has 5 buttons 
- one for writting text on canvas
- second for **uploading** text to .txt file
- third button for cleaning canvas
- and fourth counter which creates ***separate window*** and makes a list of catched ants

## Why is it helpfull? 
Ants have special times when they have nuptial flights and it's for every species individual. In my opinion it's practical to have  
stored data about it for my specific location bc for same specie it might be different in Slovak mountain than in Italy.
It is also simple app which is just designed to do simple job with text files and can be used in **different spheres**
